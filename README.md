## 🚀 WorkComposer

**WorkComposer** is a full-stack workforce productivity and time-tracking platform that I have been actively developing across three connected applications:

- **Frontend** — Next.js dashboard for organizations, users, managers, reports and settings
- **Backend** — Node.js/Express API with MongoDB, authentication, permissions, tracking, reports and integrations
- **Desktop** — Electron tracking client with workstation monitoring and browser automation

### WorkComposer Features

- 🔐 Authentication, email verification and refresh-token authentication
- 👥 Organization, user, team, manager and role management
- 🛡️ Role-based permissions and report access control
- ⏱️ Time tracking and work/break sessions
- 📊 Attendance, activity and productivity reports
- 🖥️ Application usage tracking
- 📸 Screenshot tracking
- 🖱️ Keyboard, mouse and activity tracking
- 💤 Idle detection
- 📍 Location tracking
- 🌎 User-configurable timezone handling
- 📋 Project and task management
- 🔑 API keys and API access logs
- 💳 Stripe subscriptions and billing
- 🔗 Third-party integrations including Jira, Asana and Slack
- 📧 Scheduled daily and weekly reports
- 🔎 Application productivity classification
- 🖥️ Desktop tracking bar and Electron IPC integration
- 🌐 Chromium-based browser time tracking using C#/.NET and Windows UI Automation
